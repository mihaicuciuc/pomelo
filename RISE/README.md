# RISE
Radiatiile Ionizante: Sesiune Experimentala este un proiect educational menit sa promoveze intelegerea stiintei radiatiilor ionizante. Activitatile proiectului sunt realizate cu sprijinul Ministerului Educatiei si Cercetarii - UEFISCDI, proiect nr. PN-IV-P10-SS-SC-2024-0189, finantat prin PNCDI IV.
